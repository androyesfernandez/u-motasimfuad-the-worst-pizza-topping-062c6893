# The Worst Pizza Topping

One funny line pitching the worst pizza topping imaginable: dishwasher pods. The line sells the topping as a feature — one bite foams up and dinner starts doing the dishes inside your mouth — a terrible topping pitched with a straight face and a surprising turn. The program writes exactly that single line (117 characters, no trailing newline) to `/output/entry.txt`.
